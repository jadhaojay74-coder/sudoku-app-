# 🧩 Sudoku Web App

A clean, interactive Sudoku game built with vanilla JavaScript, HTML5, and CSS3.

## ✨ Features
* Classic 9x9 Sudoku grid layout
* Interactive cell selection and number input
* Responsive design for desktop and mobile devices
